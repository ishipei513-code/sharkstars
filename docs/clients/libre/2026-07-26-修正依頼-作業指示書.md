## ② クラス内容：スケジュール表の差し替え

**原因が判明しました。** スケジュール表は画像で、2ページで別々の画像が使われていました。

| ページ | 使用中の画像 | 状態 |
|---|---|---|
| スケジュール（/schedule/） | `2026/01/image_2026_1_28-1024x364.png` | ✅ 最新 |
| HOME | 同上 | ✅ 最新 |
| **クラス内容（/class/）** | `2023/03/new.s2.png` | ❌ **2023年の古い画像** |

### 作業手順

クラス内容ページの下部、「またスケジュールに関しましては、以下の画像の割り当てになります。」の下にある画像を差し替えます。

1. 古い画像（alt属性が「ニュースケジュール」、幅2388px）を削除
2. **メディアライブラリから既存の `image_2026_1_28` を選択して挿入**
   （新規アップロードはしないこと。同じ画像が3つ増えて、次回また食い違う原因になります）

### 実際の差分（参考）

古い画像と新しい画像では、以下が変わっています。表の作り直しは不要ですが、念のため確認用に記載します。

- クラス名の変更：`総合格闘技` → `MMA`／`寝技` → `グラップリングMMA`
- 火曜・木曜の午前に「パーソナル（※要予約）」が追加
- 月曜午前が キックボクシング → MMA に変更
- 土曜のフリートレーニングが 13:00〜17:00 → **11:00〜14:00** に変更
- 21:00〜22:00 の枠に「スパーリング」（火）「中級者＆上級者スパーリング」（金）が追加

> **今後のために：** スケジュール画像はクラス内容とスケジュールとHOMEの3ページに埋め込まれています。
> 次回スケジュールを更新するときは3ページすべて差し替えが必要です。

## ③ レディースクラス：サーキットトレーニングの記述を削除

**対象：クラス内容ページ（/class/）「レディースクラス」セクション**

以下の1文をまるごと削除します。

```
最後にサーキットトレーニングを行うので理想の身体づくりやダイエット目的の女性には最適です。
```

削除後のレディースクラスの本文（2文になります）：

```
キックボクシングをメインにパンチやキックのレクチャーをします。
その後ミットやディフェンス、オフェンスの練習をしていただきます。
```

> **確認したいこと：** この1文を削除すると「理想の身体づくり・ダイエット目的の女性に最適」という
> 訴求も一緒に消えます。レディースクラスで一番効く売り文句なので、残したい場合は
> 削除ではなく以下に差し替えます（サーキットの記述だけ落とす形）。
>
> ```
> 理想の身体づくりやダイエット目的の女性にも最適です。
> ```
>
> ただし、この文はサーキットトレーニングを根拠にした訴求だったので、
> 現在の内容で言い切れるかはリブレ様のご判断が必要です。**指示がなければ丸ごと削除で進めます。**
