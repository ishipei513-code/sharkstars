## 今日やったこと

### 1. トップのファーストビューを全面刷新（参照：vessel-for.jp）

設計書：`docs/superpowers/specs/2026-10-24-marin-top-fv-menu-design.md`

- 100svh の**全面写真3枚クロスフェード**（6秒間隔）。次の1枚を手前に重ねてフェードインさせ、
  切替中に下地が透けて濁るのを防いでいる
- 下端に**波帯**。波の稜線をまたいで白の特大英字 `MARIN VISITING NURSE`、上に小さく
  「いのちの、そばに。」
- **波の塗りとカーブ文字は同一SVG・同一viewBox**。別SVGに分けて `preserveAspectRatio` を
  変えると、幅によって文字が稜線からずれる
- 文字は `textPath` 1本。参照サイトは1文字ずつSVGグリフをGSAPでモーションパス配置しているが、
  重く崩れやすいので不採用
- 波帯の青は直下の `.marquee` と同じ `--blue` なので、**そのまま繋がって1枚の海になる**
- hero画像は元画像(1920x1280)から1920幅WebPを再書き出し（`hero-0*-1920.webp`）、srcsetで出し分け

### 2. 動きを追加

- **カーブコピーが波に乗って右から流れ込む**：`textPath` の `startOffset` を 150%（パス終端の外）
  から定位置へイージング。曲線に沿った1文字ごとの回転はブラウザが処理する。
  英字0.48秒後に1.55秒、日本語0.62秒後に1.35秒
- **オープニングの幕**：マリンブルーのベタ面が0.95秒で剥がれて写真が出る。
  **2回目以降は出さない**（sessionStorage。判定は描画前に必要なのでheadにインライン）
- `prefers-reduced-motion` では幕を `display:none`、コピーは最終位置のまま。
  ⚠ 全アニメを止めるルールがあるので、`display:none` が無いと**幕が永久に残って青一色になる**

### 3. 全画面メニュー＋透明ヘッダー（6ページ全部）

- トップもサブページも**写真/濃紺ヒーローに重ねる透明ヘッダー**。スクロールで白背景へ
- ロゴは白/濃色の2枚重ねを不透明度で切替（src差し替えのチラつき回避。viewBoxが同一なので成立）
- ナビのホバー下線を**4px**に（打合せメモ「グローバルメニュー ラインを太く」を回収）
- **波線ハンバーガー**をPCでも表示 → 全画面メニュー（濃紺ベタ・`backdrop-filter`不使用）
- Esc・背景クリック・リンククリックで閉じる。フォーカストラップあり。展開中は
  body を `position:fixed` にして iOS でも背景が動かない
- 旧モバイルプルダウン（`.nav.is-open` の translateY）は統合して撤去

### 4. 本番デプロイ経路を整備

**sharkstars.jp はロリポップ**（Xserverではなかった）。公開先は `/sharkstars`。

```
MSYS_NO_PATHCONV=1 python tools/deploy_marin.py --deploy --webroot /sharkstars
```

- FileZillaの保存済み設定を読んでFTPSでアップ。**認証情報は標準出力に出さない**
- `marin_new` へ上げてファイル数を突き合わせてから入れ替える方式。ダウンタイムはリネームの一瞬
- 退避先：`client/marin_old_20261024`（**10/23以前の真の旧版**）と
  `client/marin_old_20261024-092834`（FV刷新済み・サブページ展開前）
- ⚠ **Git Bash では `MSYS_NO_PATHCONV=1` 必須**。無いと `/sharkstars` が
  `C:/Program Files/Git/sharkstars` に化けてサーバーにゴミを作る（実際に作って削除した）

### 5. 本番の機密ファイル露出を遮断（マリンケアとは別件）
