## 1. 選び方の基準

写真は**役割から逆算**して置いている。きれいな順ではない。

| 置き場所 | 求める性質 | 理由 |
|---|---|---|
| ヒーロー（第一印象） | 高解像度／人が動いている／説明が要らない | 全画面に伸びるので解像度が足りないと粗が出る |
| 導線カード・セクション写真 | 内容と1対1で対応している | 「訪問看護内容」の横に海の写真があっても意味が繋がらない |
| サブページのヒーロー | そのページの主題を1枚で言い切れる | 会社概要＝全員、採用＝働く空気、問い合わせ＝来てくれる人 |
| ギャラリー | 表情・現場の空気 | 構図より「人となり」が伝わるかを優先 |
| Instagram欄 | 日常のスナップ | 作り込んだ写真を置くと「公式感」が出て浮く |

**守っている2つのルール**

1. **同一ページに同じ写真・同じ撮影を2回出さない。** 寄り違いでも「使い回し」に見える。
2. **枠と写真の縦横比が違うぶんは必ず切れる。** 落ちる方向を実測し、被写体が残る位置に `object-position` を指定する。

## 5. 文字と写真の重なり

ヒーローのコピーは白文字。明るい被写体（白い壁・空・**グレーの制服**）に重なると沈む。
実際に「いのちの、そばに。」が制服の上で読めなくなったので、次の3段構えにしている。

1. **日本語コピーは青い帯の中に置く**（PC）。写真に重ねている限り、影や縁取りを足してもグレーの制服には勝てない。
   参考サイト（vessel-for.jp）も日本語コピーは帯の上に乗せている
2. **文字の外側に濃紺の縁取り**：`paint-order: stroke fill` ＋ `stroke: rgba(7,36,61,.55)`
   （PC英字10px／PC日本語7px／SP日本語5px／SP英字3px）
3. `.hero-scrim` の暗幕を下側で強める（62%で.34 → 78%で.56 → 最下部.64）

→ **写真を差し替えるときは、この3つを外さないこと。**

採用への導線は、帯の中にあったテキストリンク「採用情報 →」を撤去し、**ピンクの丸ボタン（`#recruitFab`）1つに寄せた**。
スマホでは丸ボタンが英字の末尾に重なるため、英字の `textLength` を240に詰め、ボタンを82pxにして角へ寄せている。

## ⚠ 書き出しの段階で人が切れていないか確認する

2026-10-24、採用CTAの `recruit-cta.webp` が **1000x1000 の正方形**で書き出されており、
原本8（6人）の**左端の1人が画像ファイルの時点で切れていた**。
CSSの切り抜き位置をいくら直しても直らない種類の不具合。

**書き出し時のルール**
- 集合写真は原本の横幅を極力残す。正方形に切らない
- 枠の縦横比を写真に合わせる（`aspect-ratio`）。
  `object-fit:cover` は枠と写真の比が違うぶんだけ必ず切る
- 斜めの切り欠き（clip-path）は人物の頭にかからない深さにする（12% → 6%）

現在：`recruit-cta.webp` = 1500x1136（原本8の x2%〜90%）、枠も 1500/1136。
