# 💳 Stripe 決済失敗プレイブック（社内用）

クレジットカード決済（Stripe・月額3,980円）が失敗したときの対応手順。

> **大原則：あなたは手で直さない。** Stripeが自動で再試行し、足りない分はお客様自身にカード更新してもらう。あなたの作業は「リンクを送るだけ」。

---

## 失敗したとき：3ステップ

1. **慌てない**
   Stripeが自動で数回リトライします（数日おき／設定による）。多くはこれで解決します。

2. **LINEで連絡**（下の定型文）＋「お支払いページ」リンクを送る
   - **リンクの取り方**：Stripe管理画面 →「**請求書（Invoices）**」→ 失敗した請求書を開く →「**顧客向けページ（Hosted invoice page）**」のURLをコピー。
   - ※または「**カスタマーポータル**」のリンクでもOK（お客様が自分でカード変更できるページ）。

3. お客様が自分でカード更新 → **自動で再請求成功**。完了。

---

## LINE定型文（コピペ用）

```
〇〇様、いつもありがとうございます😊
今月のお支払いが確認できませんでした（カードの期限切れ・残高不足などが考えられます）。
お手数ですが、こちらからカード情報のご確認・更新をお願いします🙏
👉 ［お支払いページのリンク］
ご不明点があればこのLINEにお気軽にどうぞ！
```

---

## 一度だけやっておくStripe設定（Settings → Billing 内）

- [ ] **自動再試行（Smart Retries / 再試行スケジュール）をON**
- [ ] **全部失敗した後の挙動**を決める（サブスクを「キャンセル」or「未払い(unpaid)」に）
- [ ] **失敗の通知メールをON**（自分宛＝すぐ気づける／お客様宛＝自動で催促）
- [ ] 領収書・請求書の自動送信をON

※ Stripeの画面名・場所は変わることがあるので、最終はダッシュボードで確認。

---

## それでも払われない場合

- 猶予（例：1〜2週間）をLINEで伝えたうえで、規約どおり**サイトを一時非公開**にする（「解約後は非公開」のルールに準ずる）。
- 再開は**支払い確認後**。
