## 4. ビジュアルシステム（B案「光の波打ち際」）

- **ページ全体の背景＝水色のやわらかいグラデーション**。その上に**白い角丸フレーム（カード）**でコンテンツブロックを乗せる「フローティングカード」スタイル。清潔感・軽さ。
- 配色（CSS変数で定義）：
  - `--bg`：水色グラデ（`#eafaff → #d2f0fb → #bfe8f5`）
  - `--ink`：`#0a4d6e`（濃紺）／本文 `#3a5663`
  - `--accent`：`#34b3d1`（水色）／`--deep`：`#0a5a82`
  - `--card`：`#ffffff`
- **見出しはグラデ文字**（`#0a5a82 → #34b3d1` を `background-clip:text`）
- **かわいい海の挿絵**（魚・泡・波）を控えめなアクセントに（SVG/絵文字ではなく軽量SVGを基本、過剰にしない）
- モーション：スクロールでふわっとフェードイン（控えめ）。`prefers-reduced-motion` 尊重。
- **モバイルCSSの既知の罠を回避**（`backdrop-filter`多用しない／日本語大型見出しの折返し／iOSフォームzoom=入力欄 `font-size:16px`以上／`100vh`問題／inline grid）。
