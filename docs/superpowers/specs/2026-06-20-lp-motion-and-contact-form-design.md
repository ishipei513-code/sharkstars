# SHARKSTARS 集客LP — 動きの強化 と 問い合わせフォーム追加

- 日付: 2026-06-20
- 対象ファイル: `lp/index.html` / `lp/assists/css/style.css` / `lp/assists/js/main.js`
- 種別: 既存LPへの2機能追加（モーション強化＋問い合わせフォーム）。新規依存なし。

## 目的
1. LPに「動き（見せ場）」を増やし、広告チラシ的ポップさを増幅して訴求力を上げる。
2. LINEが苦手な人向けの代替入口として問い合わせフォームを追加する（LINEは引き続き主役）。

## 方針：派手 ≠ 汎用エフェクト
「派手」は、このLPが既に持つ日本の広告チラシ的ポップさ（黄色バースト・マンガ風キラキラ・吹き出し価格）を**増幅する**方向で実現する。汎用SaaS風エフェクトは“AI生成っぽさ”が出るため不採用。

**採用（＝商品を語る見せ場）**
- ヒーロー登場の振付：ラベル → 見出し → AI3カードが1枚ずつ“配られ” → 価格バウンド → CTA。価格 `3,980` はカウントアップ＋着地でポップ拡大＋数字に光が走る。
- イントロ：検索ボックスが「近くのカフェ」と自動タイプ → 候補が順に出現。コラージュ各パーツが組み上がる（＝AEOの価値を実演）。
- 悩み：Google結果カードに検索語タイプ＋「情報が古い」警告が一度だけ赤点滅。悩み4枚は番号ポップで登場。
- 解決・特徴：SVGアイコンのドローオン（線が描かれる）。
- 料金：パネル拡大登場、`¥3,980` カウントアップ、「安心！」シールがスタンプのように押される。
- 比較表：行が上から順に出現＋SHARKSTARS列を黄色ワイプでハイライト。
- 流れ：LINEチャットを1通ずつ＋「入力中…」＋既読 で会話再生（最大の見せ場）。
- 最終CTA：見出し・ボタン登場。固定CTAは初登場時に1回だけ注目パルス。

**不採用（汎用クリシェ＝AI感）**：スクロール進捗バー／全面パララックス／紙吹雪／全要素フェード／FAQ高さアニメ。

## 技術・パフォーマンス・アクセシビリティ
- ライブラリ不使用。既存 `main.js` / `style.css` を拡張。アニメは CSS の transform/opacity のみ（60fps）。
- スクロール演出は IntersectionObserver で「画面内で一度だけ」発火 → `unobserve`。
- 常時ループは1〜2個まで（例：ヒーローのキラキラ）。それ以外はワンショット。
- `prefers-reduced-motion: reduce` で全アニメ・ループ・タイプ演出を無効化（内容は完全表示）。
- モバイル／タッチは強度を下げる（重い演出は省略）。
- 既存の `.rise` 反映と価格カウントアップは壊さず拡張する。

## 問い合わせフォーム
- 位置：FAQの下に新セクション `<section id="form">`。その後ろに既存の最終LINE CTA（`#contact`）。
- 位置づけ見出し：「LINEが使いにくい方は、フォームからでも」（＝代替入口）。
- 項目：
  - お名前（必須・`name`）
  - お店・会社名（必須・`company`）
  - 業種・エリア（任意・`area`、例：福岡市の美容室）
  - メールアドレス（必須・`type=email`・`email`）
  - ご相談・ご質問（任意・`textarea`・`message`）
- バックエンド：**Web3Forms**
  - endpoint: `https://api.web3forms.com/submit`
  - hidden `access_key` = `712577c7-2597-4906-9fed-fc7f881d0cfa`（届け先メール: sharkstars0513@gmail.com）
  - hidden `subject` = 「【SHARKSTARS LP】お問い合わせ・無料診断」
  - honeypot: `<input type="checkbox" name="botcheck" style="display:none">`
- 送信UX：
  - JSなしでも素のPOSTで送信可能（graceful degradation）。
  - JSあり：submitをintercept → fetchでAJAX送信（`Accept: application/json`）。成功でその場に完了演出（チェックマークのドロー＋「送信しました」）、失敗でその場にエラー表示。
  - 送信中はボタン無効＋スピナー。`aria-live` で状態通知。
- 同意注記：「送信で[プライバシーポリシー](https://sharkstars.jp/privacy.html)に同意」リンク。
- スタイル：LPのトークン（黄/紺/赤・角丸カード・影・Bricolage/Zenフォント）に合わせる。白カード＋フォーカス演出。

## 運用メモ（重要）
- Web3Forms の access_key はクライアント公開前提（HTMLに置いてOK）。フォームはデプロイ即動作する。
- 推奨：Web3Forms ダッシュボードでドメイン制限（sharkstars.jp）＋スパム対策（hCaptcha等）を有効化。
