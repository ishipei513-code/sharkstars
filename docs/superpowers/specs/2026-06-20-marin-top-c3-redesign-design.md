## 1. 背景・目的

クライアントとのデザイン打合せで、トップページを**やわらか水色「光の波打ち際」から、濃紺×海の演出×動き多めの大胆な方向へ刷新**する方針が決まった（参考：bluedge.co.jp の青／box1.co.jp の動き）。

訪問看護は**人材確保が経営の最重要課題**であり、トップページは利用者・ご家族だけでなく**求職者（看護師・リハビリ職）にも強く訴求する「採用に強いトップ」**とする。

### 読者層（3層・トップで分岐）
1. **利用者・ご家族** … 安心・人柄・やさしさ（直接比較は少なく、家族・ケアマネ経由で来る）
2. **求職者（看護師／リハビリ職）** … 働く環境・仲間・誇り。採用クラスターで訴求し、応募はLINEへ
3. **連携先（ケアマネ・医療/介護事業者）** … 体制・信頼・安心材料

## 3. ビジュアルシステム（C3「深海 — 力強い使命 × オシャレ × 凝りめ」）

「**濃紺で信頼感 × 強い動きでインパクト**」。編集的（エディトリアル）で、AI感・テンプレ感を避けた“オシャレ・凝りめ”。

### 配色（CSS変数・`top.css` で定義）
```
--navy-0:#06182b;   /* 最深部・背景の底 */
--navy-1:#0a2540;   /* ベース濃紺 */
--navy-2:#0a5a82;   /* 海の明るい青（グラデ上部） */
--sea:#3aa0c9;      /* 波・ゆらぎライン */
--pink:#ff5d8f;     /* アクセント（主軸） */
--ink-on-navy:#eaf4fb; /* 濃紺上の本文 */
--sub:#9fb6cc;      /* 補助テキスト */
/* オレンジ版A/B候補： --orange:#ff8a3d; */
```
- 背景はヒーロー等で **radial-gradient（上=明るい青→下=最深濃紺）** ＋ 斜めの**海ゆらぎライン**を重ねる。
- アクセントは**ピンク1色**に絞る（多色にしない＝オシャレさの担保）。

### タイポグラフィ
- 見出し：**力強い太ゴシック**（極太・字間広め）。本体の丸み系より骨太に。
- **重ね文字**：背景に大きなアウトライン英字（例 `NURSE` / `+REHA`）を薄く重ねて奥行き（凝りめの肝）。
- 数字モチーフ：採用数字・「365」等を大きく見せる。
- 欧文ラベル（`RECRUIT` `DATA` `SCROLL`）は字間を広く取り編集的に。
- フォントは Google Fonts（`preconnect`）。和文太ゴシック＋欧文サン/コンデンス系を選定（実装時に確定）。

## 4. モーション設計（動き多め）

打合せメモの「動きをつける／3D／数字動かす／文字動き／アンダーライン／求職者ボタン回る」を体現する。**動きは多めだが“滑らかで上品”に寄せ、派手なバウンド等のテンプレ感は避ける**。

| 動き | 対象 | 概要 |
|---|---|---|
| 海ゆらぎ | 背景 | 斜めライン状の波がゆっくり流れる（`seadrift`） |
| 重ね文字浮遊 | 背景アウトライン文字 | ふわりと上下（`floatY`・パララックス的） |
| 段階リビール | 見出し・ラベル・要素 | スクロール／ロードで下から順に出る（stagger） |
| アンダーライン伸び | 見出しのキーワード | 下線がにゅっと伸びる（`drawline`） |
| 回るボタン | 採用エントリーボタン | 円周の文字が回転（SVG textPath）。ホバーで加速 |
| 数字カウントアップ | 採用数字(06) | 0から実数へ。バー/リングも伸びる |
| カルーセル | ヒーロー中央写真 | 4枚を約3秒ごとにスロー横スライド |
| スライドイン | 事業内容(04)等 | スクロールで左右から入る |

### アクセシビリティ・性能（必須）
- **`prefers-reduced-motion: reduce`** 指定時：自動再生（カルーセル／海ゆらぎ／浮遊／回転）を停止、リビールは即表示。静的フォールバックを用意。
- **モバイル負荷**：重い `backdrop-filter` を多用しない／アニメは `transform`・`opacity` 中心／画像・動画は遅延・軽量化／回転や浮遊は低頻度。
- 低速回線・データセーバー時はヒーロー動画を静止画へフォールバック。

## 7. 採用の数字（ブロック06）

求職者が職場選びで見る指標を**4つ**に厳選。すべて**仮の数値**で実装し、西社長から実数を頂いて差し替える。

| 指標 | 表示方法 | 仮値（例） |
|---|---|---|
| 男女比率 | 男女の割合バー（例 男2：女8） | 仮 |
| 月平均残業 | ◯h（少ないほど良い） | 4h |
| 年間休日 | ◯日 | 120日 |
| 平均年齢 | ◯歳 | 38歳 |

- カウントアップ＋バー演出で「数字を動かす」を実現。
- ※入れ替え候補（有給消化率・離職率/定着率・職種構成・平均勤続年数）はメモに保持。確定値は西社長ヒアリング。

## 9. 技術・規約／既存サイトとの関係

- 静的HTML（ビルドツールなし）。`<html lang="ja">`。モバイル優先。
- **ファイル構成（重要・サブページを壊さない）**：
  - `client/marin/index.html` … 全面差し替え
  - `client/marin/css/top.css` … **新規**（C3トップ専用）。`reset.css` は流用
  - `client/marin/js/top.js` … **新規**（カルーセル／カウントアップ／リビール／回るボタン／`prefers-reduced-motion`分岐）
  - **既存 `css/style.css`（サブページ用・水色）は触らない**。トップだけ別系統にして整合性を保つ
- **ヘッダー/フッターの色味合わせ**：サブページとの落差を緩めるため、共有CSSを壊さない範囲でサブの header/footer に濃紺アクセントの小修正をあてる（任意・最小限。難しければ次フェーズ）。
- **プレビュー中は `<meta name="robots" content="noindex, nofollow">`** を維持（公開時に削除）。
- **SEO**：title/description/keywords、canonical（`https://sharkstars.jp/client/marin/`）、OGP＋Twitter Card は現行を踏襲。主軸キーワード「訪問看護／訪問看護ステーション／福岡市城南区／24時間対応／リハビリ 訪問」。
- **JSON-LD**：現行の `@graph`（MedicalBusiness／Organization／WebSite）を踏襲。**JobPosting は今回入れない**（実求人条件未確定）。

## 12. 確定した設計判断（2026-06-20）

1. デザイン方向＝**C3「深海」**（濃紺×海×動き多め×オシャレ・凝りめ）。アクセント**ピンク主軸／オレンジはA/B候補**。
2. **トップのみ刷新**（サブは水色維持・次フェーズでC3化）。トップは別CSS/JS系統で実装し既存を壊さない。
3. **採用に強いトップ**：採用クラスター06–08を中盤に厚く。応募＝**公式LINE**、詳細採用ページは次フェーズ。
4. ヒーロー＝海動画（当面静止フォールバック）＋**写真スローカルーセル**＋特大見出し＋回るエントリーボタン＋2CTA。
5. 採用数字＝**4つ（男女比率・月平均残業・年間休日・平均年齢）**。全て仮→実数差し替え。
6. 素材（海動画・写真・実数・実コメント）は**当面プレースホルダー**、揃い次第差し替え（本体と同方針）。
