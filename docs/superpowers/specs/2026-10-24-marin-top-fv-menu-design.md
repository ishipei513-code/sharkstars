## 2. ヒーロー（`index.html` 専用）

### 2.1 構造

```
section.hero
├ div.hero-media        … 全面写真3枚（クロスフェード）
├ div.hero-scrim        … 文字可読性のためのグラデーション
├ h1.hero-copy
│  ├ span.sr-only       … 「マリンケア訪問看護ステーション｜いのちの、そばに。」
│  ├ svg.hero-arc-jp    … 「いのちの、そばに。」（小・カーブ）aria-hidden
│  └ svg.hero-arc-en    … 「MARIN VISITING NURSE」（特大・カーブ）aria-hidden
├ svg.hero-wave         … 波形の塗り（マリンブルー）
├ a.hero-scroll         … Scroll down（左下）
└ a.hero-sub            … 採用情報 →（右下）
```

### 2.2 挙動

- 高さ `100svh` / `min-height:560px`（`100vh` は使わない＝iOSアドレスバー問題）
- スライド：3枚を 6 秒ごと・1.2秒クロスフェード。アクティブ面にごく緩いズーム（scale 1→1.05 / 7s）
- `prefers-reduced-motion: reduce` のとき：自動送り停止・ズーム停止・1枚目固定
- 波の塗りパスとカーブ文字パスは**同一のベジェ曲線から生成**し、文字ベースラインが稜線に乗るように縦オフセットのみ変える
- カーブ文字は SVG `<textPath>`。PC用（viewBox 1440×240）とSP用（viewBox 390×200）の2本をCSSで出し分け、SPは右端に流して切る
- `preserveAspectRatio="none"` は**使わない**（文字が横に潰れる）。SVG全体を等比スケールさせる

### 2.3 アクセシビリティ・SEO

- `h1` は1個のまま。中に実テキスト（`.sr-only`）を持たせ、装飾SVGは `aria-hidden="true"`
- 既存のJSON-LD・canonical・OGPは変更しない
- 波帯の文字色は白。写真側に重なる部分は `.hero-scrim` のグラデーションでコントラストを確保

### 2.4 画像

- 現 `hero-01〜03.webp` は 1200×800 で全面表示には不足 → **git に残る元画像 1920×1280**（`bdc08a5^` 時点の `hero-0*.jpg`）から 1920 幅 WebP を再書き出し
- `srcset`（1200w / 1920w）＋ `sizes="100vw"`
- 1枚目は `fetchpriority="high"` + eager、2・3枚目は `loading="lazy"`
- 目標：1920版は各 250KB 以下（q72 前後で調整）

### 2.5 撤去するもの

| 撤去 | 理由 |
|---|---|
| `.hero-video`（`hero-waves.mp4`） | 素材が未入手でポスター画像にフォールバックしたまま。全面写真が主役になるので役目が消える |
| `.hero-ghost`（NURSE / +REHA） | 1画面1メッセージに反する |
| `.hero-waves`（CSS波3本） | 新しい波帯に置換 |
| `.hero-eyebrow`（RECRUIT & CARE） | 同上 |
| `.hero-carousel`（枠付き・最大560px） | 全面写真スライダーに昇格 |
| `.hero-title`（1文字ずつアニメの大見出し） | カーブ文字に置換 |

※ 撤去対象のCSSとJSも併せて削除する（死んだルールを残さない）

## 3. ヘッダー（まず `index.html`）

- トップのみ：写真の上に**透明ヘッダー**を重ねる（`position:absolute` / `logo_white.svg` / 白文字ナビ）
- スクロール（`scrollY > 20`）で既存の白背景ヘッダー `is-scrolled` に切り替え、ロゴを `logo.svg` に戻す
- ナビのホバー下線を**太く**（2px → 4px）：打合せメモ「グローバルメニュー ラインを太く」の回収
- 右端に**波線ハンバーガー**を全幅で表示（PCでも出す）。現状の3本線は波線SVGに置換

---

## 4. オーバーレイメニュー

- 全画面・**濃紺ベタ**（`--head #0c2f4d`）。`backdrop-filter` は使わない（モバイルで重い／過去に踏んだ罠）
- 日本語＋英字併記のメニューを2列・特大表示：トップ/TOP・採用情報/RECRUIT・訪問看護内容/SERVICE・会社概要/COMPANY・お問い合わせ/CONTACT・プライバシーポリシー/PRIVACY
- 下部に罫線、TEL・住所・コピーライト
- 開く：パネルがフェード＋項目が 40ms ずつ遅れて立ち上がる。`prefers-reduced-motion` では即表示
- 閉じる：× ボタン／Esc／リンククリック／背景クリック
- 開いている間は `body` のスクロールをロック、フォーカストラップ、`aria-expanded` / `aria-controls` を正しく更新
- 既存のモバイル用プルダウンナビ（`.nav.is-open` の max-height 方式）は**オーバーレイに統合して撤去**
