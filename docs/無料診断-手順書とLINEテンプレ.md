# 🔎 無料診断（AI検索 見え方チェック）手順書＋LINEテンプレ（社内用）

リード（見込み客）から「店名・地域」が届いたら、これに沿って **約10分で診断 → LINEで返信**。
スタンスは売り込みではなく「**一緒に現状確認**」。最後に自然に〈月3,980円の土台づくり〉へつなぐ。

> **大原則**：ダメ出しではなく「**伸びしろ**」で伝える。断定・煽りはしない（→ §4）。診断だけで終わってもOK。信頼が次につながる。

---

## 0. 診断とは（相手にはこう説明する）

> 店名と地域を送るだけ。いま **Google・ちゃっぴー（chatGPT）・Gemini** で“どう見えているか”を**無料でチェック**して、**「何を直せば見つかりやすくなるか」までLINEでお伝えします。**

※「無料診断」という言葉だけだと中身が伝わらないので、LP・LINEではこの一文をセットで使う。

---

## 1. 最初にもらう情報（最低限）

- [ ] 店名／会社名（正式名称）
- [ ] 地域（市区町村）
- [ ] 業種
- [ ] （あれば）今のHPのURL・InstagramなどSNS・Googleマップ上の店名

足りなければLINEで「正式な店名と地域だけ教えてください😊」と一言。

---

## 2. 診断チェックリスト（5ステップ・約10分）

各ステップを **◎（良い）／△（あと一歩）／×（出ていない）** でメモする。

### STEP1　店名でGoogle検索
「店名」「店名＋地域」で検索。
- ◎ 公式情報（HP / Googleマップ）が一番上に出る
- △ SNSや他サイト（食べログ・エキテン等）が先に出る／情報が古い
- × ほぼ何も出ない・別の同名店が出る
- 👀 見る点：正式情報の出方・上位の中身・情報の鮮度

### STEP2　「地域＋業種」で検索
例：`福岡 美容室` / `久留米 外壁塗装` / `〇〇市 整体`
- ◎ 検索結果やマップに自店が出る
- △ 競合だらけで埋もれている
- × まったく出ない
- 👀 見る点：お客さんが実際に打つ“入口ワード”で存在できているか

### STEP3　ちゃっぴー（chatGPT）・Geminiで聞く ← ★ここが一番の差別化
例：`〇〇市でおすすめの〇〇は？` / `〇〇というお店について教えて`
- ◎ 名前が挙がる／正しく説明される
- △ 業種の一般論は返すが、自店は出てこない
- × 「分かりません」または誤った情報を答える
- 👀 見る点：AIに**認識されているか／内容が正しいか**

### STEP4　Googleマップ・SNS・今のHPの“中身”
マップ（営業時間・写真・クチコミ）、Instagram、HPに
**事業内容／地域／料金／強み／問い合わせ先** が揃っているか確認。
- 👀 見る点：AI・検索が読み取る“材料”が足りているか（情報が無いとAIは紹介できない）

### STEP5　改善点を1〜3個にしぼる
× や △ のうち、**効果が大きい順に最大3つ**だけ選ぶ（多すぎると伝わらない）。
よくある改善例：
- Googleマップ未登録 → 登録する
- HPに料金・メニューが無い → 明記する
- AIに出てこない → 事業内容・地域・強みを整理したページを持つ

## 3. LINE返信テンプレ（コピペ用）

構成は必ず「**いまの状態 → 直すと良いポイント3つ → 土台づくりへ**」。

### 【基本形】
```
〇〇様、診断ありがとうございます😊
いまの「見え方」を確認しました！

■ いまの状態
・Google検索：（例）店名では出ますが「地域＋業種」だと埋もれ気味でした
・ちゃっぴー(chatGPT)/Gemini：（例）まだお店の名前は出てきませんでした
・マップ/SNS/HP：（例）料金や強みの情報が少なめでした

■ ここを直すと“見つかりやすく”なります
① 〇〇
② 〇〇
③ 〇〇

この「見つかる土台」は、制作費0円・月3,980円（税込）でまるごとご用意できます。
気になる点だけでもお気軽にどうぞ！
```

### 【パターンA：AIにも検索にもほぼ出ない人】
```
〇〇様、ありがとうございます😊
正直にお伝えすると、いまは Google でも ちゃっぴー(chatGPT)/Gemini でも、
〇〇様のお店の情報がほとんど出てこない状態でした。

裏を返せば、ここを整えるだけで「見つかる」状態に大きく近づきます💡
まずは ①基本情報の整理 ②地域＋業種で見つかるページ ③マップ登録 の3つが効きます。

その土台づくりが、制作費0円・月3,980円（税込）です。
「まずネットでちゃんと見つかりたい」方にちょうどいいと思います。
```

### 【パターンB：HP・SNSはあるが古い/情報不足の人】
```
〇〇様、ありがとうございます😊
SNS（やHP）は拝見できました！ ただ、料金・メニュー・地域などの情報が
1か所にまとまっていないので、検索やAIが「どんなお店か」を読み取りにくい状態です。

情報を整理したページが1つあるだけで、ぐっと見つかりやすくなります。
いまの素材を活かして作れるので、制作費0円・月3,980円（税込）で土台を整えられます。
```

> 送ったあとは追わない。返信が無くてもOK。後日「その後いかがですか？」程度の軽い一言まで。

---

## 4. やってはいけない言い回し（重要・要暗記）

- ❌「**必ず1位になります**」「上位表示を保証」→ 景表法アウト。⭕「**見つかりやすくします**」止まり。
- ❌「**今のままだとヤバい/手遅れ**」など過度な煽り → 不信のもと。
- ❌ 競合や他社制作会社の**名指し批判**。
- ❌ 嘘・誇張（出ていないのに「出てます」等）。診断は**正直さが武器**。
- ❌ 専門用語の押し付け（SEO/AEO/インデックス…）→ 「見つかりやすさ」など平易な言葉に。

---

## 5. 返信の目安・運用

- **1〜2営業日以内**にLINEで返す（送ったまま放置しない安心感）。
- 診断のネーミングは LP・会話で「**AI検索 見え方チェック（無料診断）**」で統一すると価値が立つ。
- 1件あたりの所要は慣れれば**10分前後**。スクショを2〜3枚撮って添えると説得力が上がる。
