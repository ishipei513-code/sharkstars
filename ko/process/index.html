본문으로 건너뛰기

Process

문의부터 운영 개시까지

전 7단계, 최단 2개월로 일본 시장에 릴리스가 가능합니다.
각 단계에서의 산출물과 소요 기간을 명기하고 있습니다.

서비스 흐름 전 7단계

표준 스케줄: 계약부터 3개월 만에 납품 → 운영 지속

01
소요 시간 5분

문의

무료 진단 폼 또는 메일로 문의해 주십시오. 한국어·일본어 어느 쪽이든 OK입니다. 연락 후 24시간 이내에 한국 측 파트너가 답변드립니다.

  • 첫 답변 (24시간 이내)
  • 미팅 일정 조율
02
소요 30분 + 3영업일

무료 진단 (30분 Zoom)

귀사의 현재 상태·과제·목표를 한국어로 청취. Zoom에서 30분 미팅 후 기술 감사를 실시하여 3영업일 이내에 진단 리포트를 납품합니다. 계약 의무 없음, 무료입니다.

  • 청취 미팅 (한국어)
  • 기술 감사 리포트 (PDF)
  • 개선 우선순위 제안
03
3~7일

제안·견적

진단 결과를 반영한 최적 요금제(베이직/스탠다드/프리미엄)의 제안과 상세 견적을 제출. 한국 측 파트너가 한국어로 정중하게 설명해 드립니다.

  • 제안서 (한국어판)
  • 상세 견적서
  • 스케줄안
04
3~14일

계약·킥오프

업무 위탁 계약서(한일 병기)를 체결. 착수금 30~50%의 입금 확인 후 킥오프 미팅을 개최하여 전체 스케줄·담당자·커뮤니케이션 수단을 확정합니다.

  • 업무 위탁 계약서 (한일 병기)
  • NDA 비밀 유지 계약
  • 착수금 입금
  • 킥오프 미팅
05
Week 1~2

전략 설계

일본 시장 대응 키워드 설계, 콘텐츠 맵, 사이트 구조(IA)를 확정. 구조화 데이터 설계, hreflang 구현 계획, llms.txt 초안도 병행하여 진행합니다.

  • 키워드 설계서
  • 사이트 구조도
  • 콘텐츠 맵
  • 기술 구현 계획
06
Week 3~12

제작·구현

일본어 네이티브에 의한 카피라이팅, 디자인, HTML/CSS 구현, 구조화 데이터·hreflang·llms.txt 배치, GBP 등록(MEO), PR TIMES 릴리스를 병행하여 실시. 중간에 2회의 리뷰 미팅을 개최합니다.

  • 본공개 사이트 (일본어)
  • GBP 등록 완료
  • 구조화 데이터 구현
  • llms.txt 배치
  • 중간 리뷰 × 2회
07
Month 4~지속

공개·월간 운영

본공개 후 Search Console 등록, 사이트맵 전송, 첫달 리포트 제출. 이후는 월간 리포트로 KPI 공유·개선 시책 실시·추가 콘텐츠 제작을 지속합니다.

  • 본공개
  • 월간 리포트 (매월 초)
  • 정례 미팅 (월 1회)
  • 지속적 개선 시책

월간 운영에 포함되는 것

월 운영비로 지속적으로 귀사의 검색 존재감을 키웁니다

월간 리포트

검색 순위, 유입수, AI 인용 상황, GBP 노출 횟수, 리뷰 등의 모든 지표를 투명하게 공유. 개선 제안 포함.

정례 미팅 (월 1회)

리포트 설명·다음 달 시책의 합의 형성. 한국 측 파트너 경유로 한국어 대응.

신규 콘텐츠 제작

요금제별로 월 ○개의 SEO 기사·블로그·랜딩 페이지 추가. 모두 일본어 네이티브 품질.

기술 감시·수정

Core Web Vitals 저하, 인덱스 문제, 구조화 데이터 오류 등을 상시 감시하고 검출 시 즉시 수정.

GBP 운영 (MEO)

Google 게시의 지속 운영, 리뷰 관리, 사진 추가. 로컬 검색 존재감의 향상을 유지합니다.

AI 인용 모니터링

Otterly.ai 등으로 Google AI Overview·ChatGPT·Perplexity의 인용 상황을 추적, 개선 시책을 제안.

먼저 Step 01부터

무료 진단으로, 첫걸음을

30분의 청취 + 기술 감사 리포트까지, 완전 무료.
계약 의무는 일절 없습니다.
